    About Web To-Do

    With useful widgets, functions and customization options, Web To-Do acts like productivity dashboard with a sprinkle of positive energy. The user can set their own preferance, a modern or a vintage look to the dashboard. Besides beaing pleasing to the eye, the user gets an overview of the current situation together with an inspirational quote to cultivate the positive outlook for the day.

    How to use the to-do-list

    In Web To-Do the user can add tasks by typing in the text in the input-field and pressing the Add-button, or hitting enter. The task will be saved and displayed below the input-field. If the user wishes to delete a task, they can easily do so by double clicking the task in question. If the task is completed and the user wants to check it without deleting it, that is done by simply clicking the item once.

    Customization

    To customize the dashboard, select the wanted look, modern or vintage. The profile avatar can also be customized. Choose one of our profile avatars that fits your liking.
